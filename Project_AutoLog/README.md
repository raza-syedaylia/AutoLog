# AutoLog

**La tua auto, sempre in regola.**

AutoLog è una web app che raccoglie in un unico posto tutto quello che riguarda la tua auto: scadenze (bollo, assicurazione, revisione, tagliando), spese e costo al chilometro.

## Problema

Molti automobilisti dimenticano le scadenze dell'auto, rischiando multe o guasti, e non sanno quanto spendono davvero ogni anno. Le informazioni sono sparse tra libretto, carte e messaggi.

## Funzioni

- Gestione di una o più auto (marca, modello, targa, anno)
- Scadenzario con avvisi colorati (verde, arancione entro 30 giorni, rosso se scaduta)
- Registro delle spese (carburante, riparazioni, gomme, ecc.)
- Dashboard con spesa totale, spesa dell'anno, costo al km e spese per categoria

## Tecnologie

- HTML, CSS e JavaScript
- `localStorage` del browser per salvare i dati (nessun server necessario)

## Come usarlo

Apri `index.html` nel browser, oppure pubblicalo con GitHub Pages
(Settings → Pages → branch `main`, cartella `/root`).

## Mission

Aiutare gli automobilisti a tenere sotto controllo scadenze e spese dell'auto, in modo semplice e senza dimenticanze.

## Vision

Diventare l'app di riferimento in Italia per la gestione dell'auto, con promemoria automatici, statistiche di spesa e collegamento a officine e assicurazioni.

## Sviluppi futuri

- Login e database online (es. Firebase)
- Notifiche automatiche per le scadenze
- Esportazione dei dati in PDF/CSV
